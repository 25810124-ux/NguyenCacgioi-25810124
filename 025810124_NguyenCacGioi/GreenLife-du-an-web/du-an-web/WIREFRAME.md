# WIREFRAME – GREENLIFE

## 1. Bố cục trên máy tính

```text
+--------------------------------------------------------------------------------+
| HEADER: [LOGO GreenLife]                     [Trang chủ] [Sản phẩm] [Liên hệ]  |
+--------------------------------------------------------------------------------+
| HERO: [Tiêu đề sống xanh + mô tả + nút]                 [Ảnh cây minh họa]      |
+--------------------------------------------------------------------------------+
|                         SẢN PHẨM NỔI BẬT                                      |
|       [Thẻ 1]             [Thẻ 2]             [Thẻ 3]             [Thẻ 4]        |
|       [Ảnh]               [Ảnh]               [Ảnh]               [Ảnh]         |
|       [Tên + giá]         [Tên + giá]         [Tên + giá]         [Tên + giá]   |
+--------------------------------------------------------------------------------+
| KHỐI THÔNG ĐIỆP: Một góc xanh nhỏ, thay đổi cảm giác mỗi ngày                   |
+--------------------------------------------------------------------------------+
| FOOTER: Tên cửa hàng | Thông tin liên hệ minh họa | Điều hướng                 |
+--------------------------------------------------------------------------------+
```

## 2. Bố cục trên điện thoại

```text
+-------------------------------+
| [LOGO GreenLife]              |
| [Trang chủ] [Sản phẩm]        |
| [Liên hệ]                     |
+-------------------------------+
| [Tiêu đề sống xanh]           |
| [Mô tả ngắn]                  |
| [Nút xem sản phẩm]            |
| [Ảnh cây minh họa]            |
+-------------------------------+
| [SẢN PHẨM NỔI BẬT]            |
| [Ảnh sản phẩm 1]              |
| [Tên + mô tả + giá]           |
| [Ảnh sản phẩm 2]              |
| [Tên + mô tả + giá]           |
| [Ảnh sản phẩm 3]              |
| [Tên + mô tả + giá]           |
| [Ảnh sản phẩm 4]              |
| [Tên + mô tả + giá]           |
+-------------------------------+
| [Thông điệp sống xanh]        |
+-------------------------------+
| [Thông tin liên hệ]           |
+-------------------------------+
```

## 3. Giải thích
- Trên máy tính, phần giới thiệu chia thành hai cột; sản phẩm được xếp thành lưới bốn cột.
- Trên điện thoại, các khối chuyển thành một cột, menu được phép xuống dòng.
- Wireframe là phác thảo bố cục, không phải giao diện cuối cùng.
